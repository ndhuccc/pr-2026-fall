## 第四章路線圖

**一句話重點**：標籤交錯（如 XOR）時，一條線分不開；加線、再加層，就能分開。KP05 說只有點時怎麼長出網路；留下的問題是怎麼學權重。

### 先備與符號

**你需要先會的三件事**：

- **線性分類器**（第三章）：用一條直線（高維是一個平面）把兩類分開。直線一側的點判為一類，另一側判為另一類。
- **分數**：點代入直線的式子得到的數。例如 $g(x)=x_1+x_2-1.5$，分數為正判 A，否則判 B。
- **座標與表格**：一個點用兩個座標 $(x_1,x_2)$ 表示；我們會用小表格列出每個點的類別。

**本章用到的符號**：

| 符號 | 意義 | 說明 |
|---|---|---|
| $x_1,x_2$ | 輸入的兩個座標 | 本章的例子大多只有兩個座標 |
| $g(x)$ | 分數函數 | 分數為正判 A，否則判 B |
| A、B | 兩個類別 | 本章用 XOR 的 A、B 為主例子 |
| $y_1,y_2,\dots$ | 隱藏位元 | 每個隱藏單元輸出的 0 或 1（KP02 起） |

### 1. 這一章只問一件事

**問題**：一條線分不開的標籤，網路怎樣分開？

**起點是 XOR**（互斥或）：兩個輸入相同時是 B、不同時是 A：

| $x_1$ | $x_2$ | 類別 |
|---|---|---|
| 0 | 0 | B |
| 0 | 1 | A |
| 1 | 0 | A |
| 1 | 1 | B |

兩個 A 在一條對角線上，兩個 B 在另一條對角線上。任何一條直線，都沒辦法把兩個 A 放一側、兩個 B 放另一側。

圖說 `lec05-kp01-xor-check`：先看四個點的位置，A 在一條對角線、B 在另一條；再看那條灰線，它總是把某個 B 和 A 放在同一側。〔功能：1、3〕

![XOR 與同一條線](../assets/figures/lec05-kp01-xor-check.png)

### 3. 五個知識點的問、答與留下

**用白話先說五個詞**（後面的 KP 會逐一展開）：

- **位元**：只有 0 或 1 的數；一條線判斷「點在正側嗎」，答案記成一個位元。
- **隱藏層**：夾在輸入與最後輸出之間的一排計算單元；每個單元問一個小問題。
- **編碼**：把一個點的所有位元連起來，例如 $(1,0)$，像替點貼上「位置標籤」。
- **虛擬碼**：寫得出來、卻沒有任何輸入點得到的編碼。
- **偵測器**：一個單元，只在輸入的編碼剛好等於某個目標碼時才回答「是」。

| 知識點 | 問 | 答 | 留下 |
|---|---|---|---|
| KP01 一條線不夠 | XOR 有任何一條線分得開嗎？ | 兩個 A 的分數和必為正，兩個 B 的分數和必不大於 0，卻是同一個式子，矛盾。 | 要改的是邊界的組合，例如兩條線夾出一條帶。 |
| KP02 先編碼再分類 | 兩個判斷怎麼用網路做出來？ | 兩條線各給一個位元，四個點只得三種編碼，輸出層一條線分開 A 與 B。 | 線更多時，輸出層還夠用嗎？ |
| KP03 編碼與極限 | 更多線之後，一個切面分得開所有標籤嗎？ | 有些分得開，有些不行（底面 A、B 沿對角交錯）。 | 切不開的標籤要再加一層。 |
| KP04 逐碼偵測 | 怎樣在編碼之上再加一層？ | 偵測器分數 $=0.5-$ 不吻合的位元數，輸出層用「或」合併。 | 只證明夠用，網路要怎麼從點長出來？ |
| KP05 從點長網路 | 只有帶標籤的點，網路怎麼長出來？ | 主要節點分一次，輔助節點處理混雜群，增加位元純化。 | 全對只是這批點；先固定架構再學權重。 |

### 4. 回顧：整個網路與四個提醒

圖說 `lec05-kp04-stages`：先看輸入，再看隱藏編碼、偵測器、輸出四個階段，每一階段只接上一階段的結果。〔功能：1〕

![網路的四個階段](../assets/figures/lec05-kp04-stages.png)

**常見迷思**：構造出夠用的網路，就表示權重已學到、或這是最小的網路。構造只證明夠用。

**四個提醒**：

1. 固定編碼上，一個切面有極限。
2. 矛盾標籤不可能全對。
3. 全對只是這批點全對。
4. 構造證明夠用，不代表權重已學到或網路最小。
