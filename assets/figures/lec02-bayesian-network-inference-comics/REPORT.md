## 數學與語意核對

通過：以Python獨立列舉全部16個二元聯合狀態，總機率為1，再以邊際除法核對逐站計算。

| 查詢 | 全精度結果／漫畫顯示 |
|---|---|
| P(z=1∣x=1) | 0.46 |
| P(w=0∣x=1) | 0.631 |
| P(y=1), P(z=1), P(w=1) | 0.36、0.474、0.3711 |
| P(z=1∣w=1) | 0.574777687955，約0.5748 |
| P(y=1∣w=1) | 0.327405012126，約0.3274 |
| P(x=0∣w=1) | 0.403395311237，約0.4034 |

- 漫畫07–10使用簡報的完整證據機率0.3711；原講義部分算式先捨入到0.371，不能拿該捨入分母精確得到0.5748。未更動講義正文。
- 漫畫03的 L^(n−2) 限定1個證據節點、1個查詢節點、其餘每變數L種值，表示暴力列舉組合數。
- 漫畫09保留鏈上的 y ⟂ w ∣ z 條件，反推仍可對中介加總。漫畫10特別標清楚最後問的是x=0。
- 漫畫11只在f只含a、g只含b時使用該分配律例子；收據為直覺比喻。漫畫13用無數值比例的通用示意，沒有未驗證的特定順序成本。
- 漫畫12的L⁵/L²、1000倍限於來源的量級模型；實際操作次數仍含常數、節點數與中間表大小。
- 漫畫14區分模型依賴、具有因果解釋的模型、查詢訊息與觀察／干預；條件化不自動翻轉原結構。未聲稱所有貝氏網路箭頭都代表因果。
- 漫畫16的菱形只有A→B、A→C、B→D、C→D四邊，用來說明忽略方向後有多條路徑，未暗示此小例一定難算。線性節點數成本需局部表大小受控；一般NP-hard不等於每例都慢。
- 漫畫17只介紹來源的取樣／變分兩族；未增加演算法步驟或速度／精確度保證。
- 目視後修正06捷徑圖、07錯誤輔助標籤、08多餘英文、09數字字形、11多餘公式、13未驗證例子、16背景網路；修訂提示詞已保留。
