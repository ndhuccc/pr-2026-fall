# 作業(Assignments)

每份作業一個資料夾 `hwNN/`,含說明與 rubric。

## 繳交流程(二擇一)

### 方式 A:GitHub Classroom(推薦,可自動評分)
1. 點選教師提供的作業邀請連結
2. 系統自動為你建立私人作業 Repo
3. 推送程式碼,Actions 自動執行測試並顯示結果

### 方式 B:Fork + Pull Request
1. Fork 本 Repo(建議設為私人 fork,避免他人看到答案)
2. 在 `submissions/<學號>/hwNN/` 放置作業
3. 發出 PR,套用 PR 範本

> 成績與回饋以私訊或校內系統通知,**不在公開 PR 中公布分數**。
