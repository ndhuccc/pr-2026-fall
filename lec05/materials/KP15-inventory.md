# 第四章 KP15 盤點(2026-10-25)

來源:第四章網頁 §4.14「多項式分類器:能力很強,代價驚人」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:新座標怎麼造?多項式展開的能力與代價是什麼?
- **一句話結論**:把次數總和不超過 r 的乘積項全寫出來當新座標;一個交互項 x₁x₂ 就解 XOR(g=−¼+x₁+x₂−2x₁x₂,二維是雙曲線);項數 k=(l+r)!/(r!l!),l=10、r=10 就有 184,756 項。
- **故事大綱**:二階展開 → XOR 一個交互項 → 雙曲線 → 項數公式 → 組合爆炸 → 記憶體(1.48 GB、273 GB) → 月牙實驗(r=3 新點 93.2%) → 階數過頭(r=10 新點 55.5%、條件數 3.25 升到 4.4 百萬) → 延伸:核內積預告、練習、解題。
- **補充**:月牙實驗、條件數、記憶體估算、核內積驗算皆為本講義自行設計並由程式重算,已標〔補充〕。
- **術語**:多項式分類器、交互項、條件數。
- **不含**:核方法本身(KP19)、維度詛咒(第 5 章)。
