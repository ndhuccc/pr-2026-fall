# 第四章 KP22 盤點(2026-10-25)

來源:第四章網頁 §4.19.2「穩健統計迴歸與 ridge regression」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:資料裡有一個錯得離譜的點時,最小平方會怎樣?怎麼辦?
- **一句話結論**:Huber 把大誤差降成線性,ε-不敏感忽略小誤差(得稀疏),脊迴歸以平方誤差加等式得閉式解(失稀疏);脊迴歸抗共線,不抗離群點。
- **故事大綱**:離群點(斜率 2.01→2.69) → 穩健損失 → Huber 實驗(2.10) → ε-不敏感迴歸 → ε 的影響(58→2 個支撐向量) → 脊迴歸 → 共線與穩定 → 四種方法比較 → 延伸:門檻 c、練習、解題。
- **補充**:離群點與 Huber 實驗、ε 掃描、共線例子、四種方法比較、c 掃描與練習皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出 Huber 仍略偏、ε 大則稀疏但粗、脊迴歸不抗離群點。
- **術語**:離群點、穩健損失、ε-不敏感損失、脊迴歸。
- **不含**:決策樹(KP23)。
