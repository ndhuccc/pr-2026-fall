# 第四章 KP09 盤點(2026-10-25)

來源:第四章網頁 §4.8「代價函數的選擇:cross-entropy、softmax 與貝氏訓練框架」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:平方誤差有什麼毛病,分類該用什麼代價?
- **一句話結論**:交叉熵不被 sigmoid 斜率壓掉,δ=y−ŷ,錯得越離譜修得越用力;多類別用 softmax;判別式學習與貝氏訓練是另外兩條路。
- **故事大綱**:平方誤差兩個毛病 → 高原 → 交叉熵約掉斜率 → 單神經元訓練對比(5 對 85 個 epoch) → 概似 → softmax → 判別式學習(離群點對照) → 貝氏訓練(後驗變尖) → 延伸:起點越錯(14 對 88141)、練習、解題。
- **補充**:單一 sigmoid 神經元的訓練對比、離群點對照例、高斯後驗例都是本講義自行設計,數字由程式重算,已標〔補充〕;δ 的符號統一為 −∂J/∂net(來源的交叉熵 δ 寫成 ŷ−y)。
- **術語**:高原、交叉熵、概似、softmax、判別式學習、貝氏訓練。
