# 第四章 KP24 盤點(2026-10-25)

來源:第四章網頁 §4.21「結合分類器:product、sum、多數投票與貝氏觀點」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:把分類器合起來到底圖什麼?
- **一句話結論**:最好的分類器也會在別人答對的樣本上出錯,互補資訊是結合的全部價值;乘積與加總各有 KL 推導,乘積推導乾淨但輸出接近零時脆弱;多數投票趨近 100% 靠的是不成立的獨立假設;沒有萬靈丹。
- **故事大綱**:互補資訊(3 分類器投票 86.2% < 最好的 87.8%) → 乘積規則 → 加總規則 → 一票否決 → 多數投票 → 獨立的幻覺(99.99% 對 87.7%) → 製造多樣性 → 貝氏觀點與怎麼記 → 延伸:中位數、練習、解題。
- **補充**:三分類器比較、一票否決例子、獨立幻覺實驗、多樣性實驗、中位數例子、練習皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出結合不保證改善、V 最大的不是最準的。
- **術語**:KL 距離、乘積規則、加總規則、多數投票、多樣性。
- **不含**:Boosting 與 AdaBoost(KP25)。
