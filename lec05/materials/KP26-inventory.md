# 第四章 KP26 盤點(2026-10-25)

來源:第四章網頁 §4.23「類別不平衡問題」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:一類只有 20 筆時,連「準確率很高」都可靠嗎?
- **一句話結論**:傷害來自簡單性偏好與稀有類的交互作用,且要與任務難度、資料量一起看;對策是改資料或改代價,都是召回與誤報的取捨。
- **故事大綱**:準確率的陷阱(全判多數 98.0%) → 簡單性偏好 → 難度與資料量 → 改資料 → 聚焦重抽樣 → 改代價 → 對策比較 → 怎麼記 → 延伸:平衡準確率、練習、解題。
- **補充**:各實驗皆為本講義自行設計的合成資料,由程式重算,已標〔補充〕;如實標出對策使精確率與準確率下降、聚焦欠採樣對留幾個點很敏感、少數類僅 10 點時簡單任務也差。
- **術語**:類別不平衡、召回率。
