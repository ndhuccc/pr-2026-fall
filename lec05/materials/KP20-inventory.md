# 第四章 KP20 盤點(2026-10-25)

來源:第四章網頁 §4.19「超越 SVM:核技巧的通用化與 kernel perceptron」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:別的只用內積的演算法也能像 SVM 一樣升維嗎?
- **一句話結論**:核技巧是三步配方(只含內積、內積換 K、解寫成訓練點的組合);核化的歐氏分類器像 Parzen,kernel perceptron 用計數器 αᵢ 而不算 w;損失函數決定演算法的個性。
- **故事大綱**:三步配方 → 核化的歐氏分類器 → 同心環比較(拿掉 θ 只剩 79.8%) → 核感知器 → 4 點手算 → 同心環實驗(線性 500 輪不停、核 8 輪) → 四種損失 → 損失的性格 → 延伸:logistic 要除以 ln 2、練習、解題。
- **補充**:同心環比較、4 點手算、輪數與準確率、損失表、logistic 正規化、練習皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出 θ 不能忽略與兩類相碰時輪數大增。
- **術語**:核化、核感知器、間隔值、損失函數。
- **不含**:Representer 定理與稀疏化(KP21)。
