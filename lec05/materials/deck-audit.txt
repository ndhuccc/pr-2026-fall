
== XOR 與線性分類
  先問模型能否表示答案   <- 第三章用直線分類；本單元檢查它的適用界線。
  相同座標，標籤決定可分性   <- 先固定四個輸入，再比較 OR 與 XOR 的類別。
  分數正負決定預測類別   <- 圖形直覺需要固定的判別規則，才可逐點驗證。
  一組參數可算出四個預測   <- 用同一組權重逐點計算，才能公平比較 OR 與 XOR。
  兩個正類要求分數之和為正   <- 一次失敗不代表所有直線失敗；改看任意權重的必要條件。
  負類要求同一個和非正，矛盾   <- A 類要求總和為正；現在把 B 類的必要條件相加。
  訓練能改善參數，不能改變邊界族   <- 既然沒有全對直線，增加訓練還能改變什麼？
  先解釋限制，再提出模型改變   <- 把「沒有全對直線」連到下一個問題：多條邊界如何組合？
  延伸:AND 也能用單一直線分開   <- 延伸核對：改成 AND，看看同樣四點如何被分開。
  延伸:候選線會錯；證明才排除所有線   <- 同一條候選線，改變判別方向或平手規則會改變錯誤數。
  延伸:兩條邊界可選出中間的正類   <- 單一直線失敗後，改變模型允許的邊界組合。
  延伸:固定平手規則，才能重現驗證   <- 把前面的算例與證明轉成可自行檢查的步驟。
