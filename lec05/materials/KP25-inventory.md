# 第四章 KP25 盤點(2026-10-25)

來源:第四章網頁 §4.22「Boosting 與 AdaBoost:把『弱』變『強』」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:一個只比亂猜好一點的弱分類器,能不能被提升成強分類器?
- **一句話結論**:最小化指數損失、逐級最佳化,樣本權重與 α=½ln((1−P)/P) 自然出現;做錯的點權重變大;訓練錯誤歸零後測試錯誤仍持平,邊距解釋是定性的;標籤有雜訊時會退化。
- **故事大綱**:弱變強 → 權重的誕生 → α → 權重更新(10 點手算) → 演算法與設定 → 錯誤曲線(第 17 輪訓練歸零) → 邊距解釋 → 不是萬靈丹(15% 標籤翻轉) → 延伸:負 α、練習、解題。
- **補充**:決策樁錯誤、10 點手算、重做 Example 4.3 的曲線與邊距表、標籤翻轉實驗、練習皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出測試錯誤約 200 輪後持平、單次實驗的小波動不能過度解讀、有雜訊時最低 17.8% 後升到 23.3%。
- **術語**:弱分類器、決策樁、逐級最佳化、正規化邊距。
- **不含**:類別不平衡(KP26)。
