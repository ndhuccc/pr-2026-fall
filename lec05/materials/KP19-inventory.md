# 第四章 KP19 盤點(2026-10-25)

來源:第四章網頁 §4.18「非線性 SVM 與 Mercer 核技巧」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:有沒有只留少數點、又能做非線性分類的辦法?
- **一句話結論**:SVM 只用內積,把內積換成核函數,就在沒去過的高維空間裡設計線性分類器;計算量與核空間維度無關。
- **故事大綱**:只用內積 → 二次映射恆等式 → 同心環升維 → Mercer 定理 → 核化 SVM → 同心環實驗(線性核 56.2%、二次 97.6%、高斯 96.8%) → 超參數 γ 與 C → 維度無關 → 延伸:雙曲正切核不合法、練習、解題。
- **補充**:同心環實驗、γ 與 C 掃描、特徵數表、雙曲正切核負特徵值、練習皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出 γ 過大時新點只剩 74.7%、「最好」以新點挑選、訓練仍隨訓練點數成長。
- **術語**:支撐向量、核函數、Mercer 條件、超參數。
- **不含**:核技巧的通用化與 kernel perceptron(KP20)、稀疏化(KP21)。
