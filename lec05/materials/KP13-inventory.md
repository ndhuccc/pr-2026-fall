# 第四章 KP13 盤點(2026-10-25)

來源:第四章網頁 §4.12「廣義線性分類器:把「非線性」外包給映射」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:資料在原空間用一條線分不開時,怎麼辦?
- **一句話結論**:先用固定的非線性 f_i 升維,再在新空間設計普通的線性分類器;g=w₀+Σwᵢfᵢ(x) 對權重是線性的。
- **故事大綱**:一維夾住的兩類(單一門檻最多 5/7) → 換成 (x,x²) → 回到 x 看是彎的 → XOR 加 x₁x₂ → 最小二乘權重 → 同心環(51% 對 99.5%) → 多類別 → 對照投影追蹤與「怎麼記」 → 延伸:二次特徵個數、練習、解題。
- **補充**:一維夾住例、XOR 新座標、同心環資料(來源有互動示範,本講義另以程式產生資料)、三類一維資料,都是自行設計並由程式重算,已標〔補充〕。
- **術語**:特徵映射、廣義線性分類器、正規方程、投影追蹤。
- **不含**:Cover 定理(KP14)、多項式分類器(KP15)、RBF 網路(KP16)。
