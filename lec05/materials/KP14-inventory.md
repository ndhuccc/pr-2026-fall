# 第四章 KP14 盤點(2026-10-25)

來源:第四章網頁 §4.13「Cover 定理:l 維空間的線性二分容量」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:升維真的有幫助嗎?
- **一句話結論**:維度越高,隨機標籤的點線性可分的機率越大,臨界點在 N=2(l+1)(機率剛好 1/2、相變);但升維只提高可分性,不保證泛化。
- **故事大綱**:一條線能分幾種(4 點 14 對 16,缺 XOR) → 計數公式 → 可分機率 → 相變 → 隨機實測(0.865、0.503) → 升維的效果(0.494 對 1.000) → N=100 要幾維 → 可分不等於泛化(新點 50.4%) → 延伸:為什麼是一半、練習、解題。
- **補充**:隨機實測(線性規劃)、升維前後比例、N=100 的表、隨機標籤泛化實驗皆為本講義自行設計並由程式重算,已標〔補充〕。
- **術語**:二分、一般位置、相變。
- **不含**:多項式分類器(KP15)、RBF(KP16)。
