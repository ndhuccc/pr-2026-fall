# 第四章 KP23 盤點(2026-10-25)

來源:第四章網頁 §4.20「決策樹:OBCT、分裂準則與剪枝」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:分類能不能不畫邊界,只問一連串簡單的是非題?
- **一句話結論**:每問一個單一特徵的是非題就切一刀;用熵不純度的下降量(依樣本數加權)選問題;樹的大小才是關鍵,要剪枝;單棵樹變異大,bagging 能平均掉。
- **故事大綱**:是非題 → 四件事與候選問題(9 個中點) → 不純度 → 不純度下降量(Example 4.2 重算 0.322) → 為什麼加權 → 樹要多大 → 剪枝 → 高變異與 bagging → 延伸:斜向問題、練習、解題。
- **補充**:候選問題例子、加權對照、樹深與剪枝、變異與 bagging、斜向實驗、練習皆為本講義自行設計並由程式重算,已標〔補充〕。
- **教材數字差異**:教材 Example 4.2 的 I(t_Y)=0.815、I(t_N)=1.472、ΔI=0.315,依它自己的計數重算為 0.811、1.459、0.322(用它印的數字算也只有 0.312);已在簡報與講義標出。
- **術語**:決策樹、不純度、剪枝、Bagging。
- **不含**:結合分類器(KP24)。
