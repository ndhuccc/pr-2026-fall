# 第四章 KP06 盤點(2026-10-25)

來源:第四章網頁 §4.6「從階梯到 Sigmoid，再到反向傳播的梯度推導」(2026-10-25 讀取,本機 HTML SHA-256 與先前相同:612a18d4…)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁。

- **核心問題**:要讓網路自己學權重，階梯函數沒有斜率可用，怎麼辦？
- **一句話結論**:換成 sigmoid;用連鎖律，梯度 = δ×輸入，δ 由輸出層沿權重往回算(反向傳播)。
- **故事大綱**:階梯沒斜率 → sigmoid 有斜率但越像階梯越難訓練 → 2–2–1 網路前向傳遞 → 連鎖律拆三段斜率 → 誤差訊號 δ → δ 往回分給隱藏層 → 九個權重更新一步、代價下降 → 用數值差分核對。
- **開悟時刻**:第 6 頁,隱藏單元看不到目標，卻能把輸出的 δ 乘上權重分回來。
- **主例子**:來源互動例的 2–2–1 網路(輸入 (1,0)、目標 1、權重為來源初始設定),全程同一組數字。
- **術語**:代價函數、梯度下降、sigmoid、前向傳遞、連鎖律、誤差訊號、學習率、反向傳播(皆有術語卡,先白話再名字)。
- **補充與更正**:δ 的符號統一為 δ=−∂E/∂v(來源同時寫 ∂E/∂v 與「誤差乘斜率」,差一個負號);所有算例、更新量、數值差分核對由程式重算(誤差 ≤10⁻⁶)。
- **不含**:演算法流程與實務要點(KP07)、動量與自適應學習率(KP08)、交叉熵與 softmax(KP09)。
