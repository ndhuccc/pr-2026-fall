# 第四章 KP08 盤點(2026-10-25)

來源:第四章網頁 §4.7「反向傳播的加速變形:momentum、自適應學習率、quickprop」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:梯度下降在狹長谷底又慢又來回擺,有什麼辦法加速?
- **一句話結論**:動量把上一步的 α 倍加進這一步(平的方向放大 1/(1−α) 倍、陡的方向抵銷);自適應學習率讓 μ 自己調;quickprop 用兩次斜率估谷底;加速一律以複雜度為代價。
- **故事大綱**:狹長谷底 → 為什麼來回擺 → 動量式與手算 → 指數加權平均 → 兩條軌跡 → α 的最佳值 → 自適應學習率 → quickprop 與五種做法比較 → 延伸:牛頓法、練習、解題。
- **主例子**:本講義自行設計的 J=½(w₁²+20w₂²)、起點 (−4,1)、μ=0.08(補充;來源有互動示範但無數字),所有步數與軌跡由程式重算:普通 100 步、動量 α=0.6 28 步、α≥0.9 比不用更慢、自適應 61/95 步、quickprop 5 步。
- **術語**:曲率、狹長谷底(病態代價面)、動量、指數加權平均、自適應學習率、quickprop、牛頓法(延伸)。
- **不含**:交叉熵與 softmax(KP09);Hessian 家族細節只列名稱。
