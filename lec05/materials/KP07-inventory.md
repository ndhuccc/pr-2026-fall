# 第四章 KP07 盤點(2026-10-25)

來源:第四章網頁 §4.7「反向傳播演算法流程與實務要點」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:有很多筆資料時,訓練怎麼從頭跑到尾,哪些實務因素決定成敗?
- **一句話結論**:先給起始值,之後每個 epoch 重複前向、反向、更新到停止條件;學習率、起始值與區域極小值決定快慢與成敗。
- **故事大綱**:四步驟(epoch、批次) → 第一個 epoch 前向 → 反向與更新 → J 曲線與停止條件 → 學習率兩難 → 全 0 起點 → 區域極小值(卡住的起點) → 逐筆訓練 → 延伸:凍結權重、練習、解題。
- **主例子**:XOR 的 2–2–1 網路與來源互動例初始權重,全部數字由程式重算(3707 個 epoch 達 J<0.0002 等)。
- **術語**:epoch、批次訓練、停止條件、初始化、區域極小值、逐筆訓練、凍結權重。
- **補充**:全 0 起點、300 組 ±3 隨機起點(176 達標、124 卡住)、逐筆模式沒有跳出卡住起點,是本講義自行做的程式實驗,已標〔補充〕;逐筆較快主要來自步長(批次 η=6 要 926 個 epoch、逐筆 η=1.5 要 924)。
- **不含**:動量與自適應學習率(KP08)、交叉熵與 softmax(KP09)。
