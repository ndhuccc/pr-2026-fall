# 第四章 KP16 盤點(2026-10-25)

來源:第四章網頁 §4.15「RBF 網路:局部反應 vs 全域反應」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:新座標能不能只對附近的資料有反應?
- **一句話結論**:RBF 以到中心的距離為引數,節點只在中心附近反應;兩個中心就解 XOR(0.135、0.368);局部讓它學得快,也讓它吃維度。
- **故事大綱**:高斯節點 → 局部對全域(等值線是圓) → XOR 兩個中心 → 回到原空間的封閉曲線 → 固定中心(環形 k=16 就 99.5%) → 中心怎麼選(k-means 更穩) → 局部的代價(l=10 只照到 40%) → MLP 對 RBF → 延伸:其他選法、練習、解題。
- **補充**:環形與月牙的中心數實驗、隨機對 k-means 比較、局部性的維度實驗,皆為本講義自行設計並由程式重算,已標〔補充〕;比較表與中心選法依來源。
- **術語**:徑向基函數、局部反應、固定中心、分群、維度詛咒。
- **不含**:通用近似定理(KP17)、PNN(KP18)。
