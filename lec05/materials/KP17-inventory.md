# 第四章 KP17 盤點(2026-10-25)

來源:第四章網頁 §4.16「通用近似定理:誰能逼近任意函數,以及逼近得多快」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:誰能逼近任意函數?逼近得多快?
- **一句話結論**:多項式、一層 sigmoid 網路、RBF 都是通用近似器,這是入場券;差別在速率(多項式 O(r^(−2/l)) 對網路 O(1/k),原因是固定基底對資料自適應基底)與最佳化的難易(非凸);多層可能更有效率。
- **故事大綱**:入場券 → Weierstrass(最大誤差 r=9 為 0.000015) → 龍格現象 → sigmoid 網路 → 一維公平比(多項式不輸) → 高維脊函數(偏袒網路) → 速率 → 基底與代價(隨機起點 5/8 成功) → 延伸:帽函數多層、練習、解題。
- **補充與誠實標註**:所有實驗為本講義自行設計並由程式重算;一維平滑目標多項式不輸;高維脊函數目標刻意偏袒網路且輸入非緊緻集;速率是最壞情況漸近式,不是實測。
- **術語**:通用近似定理、龍格現象、擠壓函數、固定基底、資料自適應基底。
- **不含**:Barron 速率的條件與證明。
