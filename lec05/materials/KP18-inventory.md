# 第四章 KP18 盤點(2026-10-25)

來源:第四章網頁 §4.17「機率神經網路(PNN):把 Parzen 估計搬進網路」(2026-10-25 讀取)。程度:大學三年級;中英文分開;主線 8 頁＋延伸 3 頁(自主學習)。

- **核心問題**:有沒有一種網路幾乎不用訓練?
- **一句話結論**:Parzen 估計是核函數的平均,一個訓練點配一個神經元;向量正規化成長度 1 後平方距離變內積(2−2xᵢᵀx),式子正好是網路形式;訓練就是抄資料,代價是全部訓練點都要留著。
- **故事大綱**:一點一個神經元 → 距離變內積 → 判別函數(只有正規化時兩種算法一致) → 網路架構 → 70° 小例 → 核寬(簡單例子不敏感) → 留多少點 → 成本(N×l) → 延伸:正規化丟掉長度(環形 49.5%)、練習、解題。
- **補充**:小例、核寬與訓練點數實驗、成本表、環形失敗實驗皆為本講義自行設計並由程式重算,已標〔補充〕;如實標出簡單例子對核寬不敏感。
- **術語**:Parzen 估計、核寬、單位範數正規化、機率神經網路。
- **不含**:非線性 SVM 與核技巧(KP19)、稀疏化(KP21)。
